# Lista

## O que é uma Lista?

Uma lista é uma estrutura de dados que armazena uma coleção ordenada de elementos. Os elementos em uma lista são acessados por um índice (posição), começando geralmente do índice 0.

## Características principais:

- **Ordenação**: Os elementos mantêm a ordem em que foram inseridos
- **Acesso por índice**: Cada elemento pode ser acessado através de sua posição
- **Tamanho dinâmico**: Muitas listas podem crescer ou diminuir conforme necessário
- **Homogeneidade**: Geralmente contêm elementos do mesmo tipo (dependendo da linguagem)

## Operações comuns:

- **Inserção**: Adicionar um elemento à lista
- **Remoção**: Remover um elemento da lista
- **Acesso**: Acessar um elemento por seu índice
- **Busca**: Procurar um elemento na lista
- **Iteração**: Percorrer todos os elementos da lista

## Implementações:

Este código implementa as seguintes operações:
- **Busca**: Encontrar um elemento na lista
- **Inserção**: Adicionar um novo elemento
- **Remoção**: Deletar um elemento existente

## Exemplos de uso:

- Armazenar uma lista de números
- Manter uma sequência de nomes
- Guardar dados de usuários
- Implementar filas e pilhas

As listas são uma das estruturas de dados mais fundamentais e amplamente utilizadas na programação.
