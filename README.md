# lab-1-trabalho - Estrutura de Dados 

O presente trabalho tem o intuito de apresentar a implementação de algumas estruturas de dados e algoritmos. Dessa forma, trabalhou-se com: Array, Heap, Lista e Arvores. 

Como auxiliar foi realizado um artigo que descreve as condições de implementação, metodologia utilizada e resultados obtidos. Entretanto, na pasta 'tree' -> 'main' pode-se ver o tempo de execução detalhadamente. 

Cada pasta terá seu README para auxilio no entendimento.
